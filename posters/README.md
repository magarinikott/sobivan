# posters workflow for sobivan.ru

всё, что связано с афишами, теперь живёт здесь.

## где менять

- данные: `/posters/posters.json`
- картинки: `/posters/assets/`

## как устроено

каждая афиша — это один объект в `posters.json`.

поля:
- `status`: `active` или `archive`
- `title`: строка под афишей
- `subtitle`: вторая строка под афишей
- `alt`: alt-текст картинки
- `image`: путь к картинке

## как обновлять дальше

### добавить новую актуальную афишу
1. положить картинку в `/posters/assets/`
2. добавить новый объект в начало списка `items` или после нужной активной афиши
3. поставить `status: "active"`

### перенести афишу в архив
1. у нужного объекта поменять `status` с `active` на `archive`
2. при необходимости переставить его ниже в списке

### поменять порядок
просто переставить объекты в массиве `items`.

## важно

основной `index.html` больше не должен редактироваться руками под каждую афишу.
он только рендерит данные из `posters.json`.
